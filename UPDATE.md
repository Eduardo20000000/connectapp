# 🚀 Updates

## 📅 7 de septiembre — ConnectApp consigue casa propia

ConnectApp da uno de sus primeros grandes pasos: se adquiere un **servidor propio** y la aplicación comienza a contar con una infraestructura preparada para funcionar fuera del entorno local.

### ☁️ Infraestructura

* Se adquiere un **servidor**.
* Se implementa **HTTPS**.
* Se configura **Cloudflare**.
* Se configura **Nginx**.
* Se registra y configura el dominio:
  **connectapp.dpdns.org**

### 💡 ¿Qué cambia?

ConnectApp deja atrás la etapa de funcionar únicamente en el computador donde fue desarrollada y comienza a utilizar infraestructura propia.

**Beneficio:** permite utilizar y probar el sistema fuera de una configuración exclusivamente local.

> El PC ya no tiene que ser el único lugar donde ConnectApp existe.
> Ahora tiene servidor, dominio y todo. Le falta solamente pagar arriendo.

# 📲 Nuevos métodos de vinculación

ConnectApp incorpora una nueva forma de conectar el celular con el computador mediante **códigos QR**, manteniendo también el método convencional mediante código.

### 📷 Vinculación mediante QR

El PC genera un código QR que puede ser escaneado desde el celular para iniciar la vinculación.

### 🔢 Código convencional

También se mantiene la posibilidad de introducir el código de vinculación manualmente.

### 💡 ¿Qué mejora?

La vinculación se vuelve más sencilla y evita depender de métodos como:

* Bluetooth.
* Buscar direcciones IP manualmente.
* Escribir direcciones largas y poco amigables.

> Porque nada dice *"quiero controlar mi PC"* como estar mirando una dirección IP y preguntándote si era `192.168.1.34` o `192.168.1.43`.

Con QR:

**Escanear → vincular → listo.** 📱

Esto permite que ConnectApp pueda establecer la conexión sin exigir al usuario conocimientos sobre redes o configuraciones complicadas.

# 2️⃣ Modo Teclado + Mouse

Cuando mover el mouse ya no es suficiente.

Este modo incluye:

### 🖱️ Mouse mejorado

* Click izquierdo.
* Click derecho.
* Un panel de mouse mejorado.

### ⌨️ Teclado

Permite escribir directamente en el computador utilizando el celular.

### 💡 ¿Para qué sirve?

Porque hay momentos en los que necesitas escribir algo en el PC y estás lejos del teclado.

Por ejemplo:

Estás acostado.

El computador está conectado al televisor.

Necesitas escribir algo.

Miras el teclado.

Está allá.

Muy lejos.

Aproximadamente **a tres metros**.

Una distancia científicamente insoportable.

Así que sacas el celular y escribes desde ahí.

**Problema resuelto.**

---

# 3️⃣ Modo Accesos Directos

El modo para quienes ya tienen claro qué aplicaciones utilizan.

Permite **subir accesos directos de aplicaciones del computador** y posteriormente abrirlas desde el celular.

Los accesos directos quedan **guardados** y son leídos cada vez que se utiliza este modo.

### ⚡ ¿Para qué sirve?

Supongamos que quieres abrir una aplicación.

Podrías:

1. Buscar el mouse.
2. Moverlo.
3. Abrir el menú.
4. Buscar la aplicación.
5. Hacer click.
6. Esperar.

O podrías:

**sacar el celular → tocar el acceso directo → listo.**

Porque aparentemente abrir una aplicación desde el menú de inicio requería demasiados pasos.

### 🏠 Ejemplo cotidiano

Estás viendo algo en el televisor desde el PC y quieres abrir rápidamente otra aplicación.

No necesitas levantarte.

No necesitas buscar el mouse.

No necesitas recordar dónde dejaste el teclado.

Solo utilizas el acceso directo desde ConnectApp.

> Tu celular probablemente estaba en tu mano de todas formas.
> Por una vez, que haga algo útil además de recibir notificaciones.
