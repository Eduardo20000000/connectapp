#  CONNECTAPP

> La telepatía de dispositvos

**ConnectApp** es una aplicación desarrollada con **Node.js** y **JavaSript** por Eduardo Layana, la app permite vincular un celular con un computador mediante un código generado por la aplicación. Una vez realizada la vinculación, podrás utilizar tu celular como un control remoto para manejar diferentes funciones de tu computador.

---

##  ¿Cómo funciona?

El funcionamiento es simple:

1. El computador ejecuta la aplicación.
2. La aplicación genera un **código de vinculación**.
3. El usuario introduce ese código en su celular en ```connectapp.dpdns.org``` (Debes logearte o crear una cuenta).
4. El celular y el computador quedan vinculados.

---

# Metodología de uso

## 1. Instalar Node.js

Para ejecutar la aplicación necesitas tener **Node.js** instalado en tu computador.

Si ya tienes Node.js instalado, puedes saltar este paso.

Si no lo tienes, descárgalo desde su página oficial:

**https://nodejs.org/**

Se recomienda instalar una versión **LTS (Long Term Support)**.

Después de instalarlo se recomienda reinicio del dispositivo

---

# 2. Ejecutar la aplicación

Una vez instalado Node.js:

1. Descarga este repositorio
2. Dirígete a la carpeta del proyecto y extráelo en algún rincón decente de tu computador.
3. Ejecuta el archivo:

```text
ejecutor.bat
```

El archivo `ejecutor.bat` se encargará automáticamente de:

* Instalar los paquetes necesarios para la app.
* Preparar las dependencias del proyecto.
* Ejecutar `app.js`.

Todo a un Enter desde la comodidad de tu hogar.

---

# 3. Vincular tu celular

Cuando la aplicación esté ejecutándose, aparecerá un **código de vinculación** generado por el computador.

### En tu celular:

1. Abre la app en tu navegador ```connectapp.dpdns.org```.
2. Inicia sesión en tu cuenta
3. Introduce el código generado por el computador.
4. Confirma la vinculación.

Una vez conectado correctamente, ambos dispositivos estarán vinculados y se hará display del control remoto.

---

#  4. ¡El poder a tus manos!

Después de realizar la vinculación:

**Tu celular se convierte en el control remoto de tu computador**

Desde el celular podrás utilizar las funciones disponibles en la aplicación para controlar el computador de forma remota.
